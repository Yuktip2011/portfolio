# 🌟 Yukti Patil — Frontend Developer Portfolio

A professional, high-performance, and responsive portfolio website built with pure semantic **HTML5**, modern **CSS3** (CSS Variables, Flexbox, Grid, Glassmorphism), and vanilla **JavaScript (ES6+)**.



## 🚀 Key Features

- **Violet & Indigo Dark Theme**: Modern dark slate background with glowing indigo/violet accents and frosted glassmorphic cards.
- **Interactive Dark / Light Mode**: Smooth theme toggling with automatic `localStorage` preference memory.
- **Dynamic Typewriter**: Hero section animated role titles (*Frontend Developer*, *React Enthusiast*, *UI/UX Crafter*, etc.).
- **Interactive Project Filtering**: Instant category filtering (`All`, `React`, `JavaScript`, `UI Design`).
- **Project Detail Modal**: Rich pop-up modal with deep project breakdowns and features.
- **Copy Email with Feedback**: 1-click clipboard copy button for `yuktip2011@gmail.com`.
- **Form Validation**: Client-side contact form verification with success alert.
- **Zero Dependencies**: Blazing fast load times with no Node/npm builds required.

## 🛠️ How to Preview Locally

### Option 1: Direct Browser
Simply double-click `index.html` or drag it into any web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Local Python Server (Recommended)
Open PowerShell or Terminal in this folder and run:
powershell
python -m http.server 8000

Then visit: [http://localhost:8000](http://localhost:8000)



## ✏️ How to Customize

1. **Update Social Profiles**:
   - LinkedIn is already configured to: `https://www.linkedin.com/in/yukti-patil-9443b838a`
   - In `index.html`, find `https://github.com` to add your specific GitHub username.
2. **Add New Projects**:
   - In `js/main.js`, update the `projectsData` array with your real project names, descriptions, GitHub links, and live demo URLs.
3. **Resume / CV**:
   - Place your resume PDF in `assets/` and link it in the navigation or Hero section.


## 🌐 Free Deployment Guide

- **GitHub Pages**: Push this folder to a GitHub repository, go to **Settings > Pages**, choose the `main` branch, and save!
- **Netlify / Vercel**: Drag and drop this folder onto Netlify Drop or import the repository in Vercel.
